# ☁️ CodeSensei 🔴

Персональный Python-ментор в Telegram. Обучение по расписанию, проверка кода через ИИ и поддержка голосовых сообщений.

🔗 **Бот в TG:** [@Code_Sensei_bot](https://t.me/Code_Sensei_bot)

---

### 🚀 Как это работает
* **Теория в 10:00** — ежедневные порции знаний и вопросы.
* **Практика в 19:00** — задачи для закрепления материала.
* **Голосовой ввод** — отвечай текстом или голосом (Whisper AI).
* **Умный фидбек** — ИИ (Llama 3.3) проверяет логику и дает советы.

---

### 🛠 Стек
* **Язык:** Python.
* **AI:** Groq (Llama 3.3 + Whisper).
* **База:** SQLite3.
* **Хостинг:** Railway.
